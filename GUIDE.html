Setup Guide

WorkoutTracker PWA

Google SSO · Google Calendar · Workout Import · Progress Tracking

1

Create a Supabase Project

Set up your database and authentication

1.1 — Create project

  • Go to supabase.com → New Project
  • Choose a name (e.g. workout-tracker), region, and strong password
  • Wait ~2 minutes for it to initialize

1.2 — Get your API keys

  • Go to Project Settings → API
  • Copy Project URL and anon (public) key

1.3 — Run the database migration

  • Go to SQL Editor in your Supabase project
  • Open the file supabase/migrations/001_workout_schema.sql from this project
  • Paste the entire contents into the SQL editor and click Run
Note: This creates all tables (programs, days, exercises, sessions, logs) and sets up Row Level Security so users only see their own data.
2

Set Up Google OAuth

Enable Google Sign-In + Calendar access

2.1 — Google Cloud Console

  • Go to console.cloud.google.com
  • Create a new project (or select existing)
  • Go to APIs & Services → Enable APIs
  • Enable: Google Calendar API and People API

2.2 — Create OAuth Credentials

  • Go to APIs & Services → Credentials → Create Credentials → OAuth Client ID
  • Application type: Web application
  • Add Authorized JavaScript origin:
    https://your-project-ref.supabase.co
  • Add Authorized redirect URIs:
    https://your-project-ref.supabase.co/auth/v1/callback
  • Copy Client ID and Client Secret
Replace your-project-ref with your actual Supabase project reference ID (visible in Project Settings → General).

2.3 — Configure Supabase Auth

  • In Supabase: go to Authentication → Providers → Google
  • Toggle Enable
  • Paste your Client ID and Client Secret
  • Save

2.4 — OAuth Consent Screen

  • In Google Cloud Console → OAuth consent screen
  • User type: External → Create
  • Add App name, support email, developer email
  • Add scopes: email, profile, https://www.googleapis.com/auth/calendar
  • Add yourself as a test user (during development)
Important: While your app is in "Testing" mode, only users added as test users can sign in. To open it to everyone, you'll need to submit for Google verification.

2.5 — Add Redirect URL in Supabase

  • In Supabase: Authentication → URL Configuration
  • Site URL: http://localhost:3000 (or your production URL)
  • Add redirect URL: http://localhost:3000/auth/callback
  • For production, also add: https://yourdomain.com/auth/callback
3

Configure Environment Variables

Create your .env.local file

Create .env.local in project root

NEXT_PUBLIC_SUPABASE_URL=https://xxxxxxxxxxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6Ikp...
NEXT_PUBLIC_APP_URL=http://localhost:3000
Note: Google Client ID & Secret are NOT needed here — they are configured directly in Supabase Auth settings. Supabase handles the OAuth flow for you.

Environment variables explained

VariableWhere to find it
NEXT_PUBLIC_SUPABASE_URLSupabase → Project Settings → API → Project URL
NEXT_PUBLIC_SUPABASE_ANON_KEYSupabase → Project Settings → API → anon (public) key
NEXT_PUBLIC_APP_URLYour app URL (localhost:3000 for dev)
4

Install & Run

Get the app running locally

4.1 — Install dependencies

cd workout-pwa
npm install

4.2 — Start the development server

npm run dev

Open http://localhost:3000 in your browser

4.3 — Build for production

npm run build
npm start
PWA Note: The service worker and offline capabilities are only active in production build. Run npm run build && npm start to test PWA features.
5

Using the App

Quick start guide for your workout tracker

Importing a workout program

  • Tap the + Import button in the bottom navigation
  • URL import: Paste any muscleandstrength.com/workouts/... URL and tap Import
  • PDF import: Download a workout PDF from muscleandstrength.com, then upload it
  • Review and edit the imported exercises — add YouTube video links per exercise!
  • Save the program

Scheduling a program

  • Go to Workouts → tap on your program
  • Choose a start date
  • Toggle Sync to Google Calendar if you want calendar events created
  • Tap Start Program — workout sessions will be auto-created!
Calendar conflicts: If you have existing calendar events on workout days, the app will warn you. You can adjust the start date to avoid conflicts.

Tracking a workout

  • On the Home screen, you'll see today's workout
  • Tap any exercise card to expand it and see all sets
  • Check off each set as you complete it
  • Tap the YouTube icon 🎬 to watch a guide video for any exercise
  • Once all sets are done, the Complete Workout button activates — tap it!

Adding YouTube video links

  • When importing, fill in the YouTube guide URL field for each exercise
  • Example: https://www.youtube.com/watch?v=...
  • The app extracts the video ID and shows a clickable link during your workout
6

Deploy to Production

Host your app and install it as a PWA

Deploy to Vercel (recommended)

  • Push your code to GitHub
  • Go to vercel.com → Import Project
  • Add environment variables: NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_ANON_KEY
  • Deploy!

Update Supabase redirect URLs

  • In Supabase → Authentication → URL Configuration
  • Add your Vercel URL as both Site URL and redirect URL
  • In Google Cloud Console, add the Vercel URL to authorized origins and redirect URIs

Install as PWA on your phone

  • iPhone (Safari): Open app URL → tap Share → "Add to Home Screen"
  • Android (Chrome): Open app URL → tap menu → "Add to Home Screen" or "Install App"
  • The app works offline for already-loaded sessions!
